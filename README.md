## 01 · About

I'm a Computer Science undergraduate at **VIT Vellore** and a Data Science student at **IIT Madras**. Most of what I know has come from taking systems apart: building a small thing, breaking it, reading the logs, and figuring out why it behaved the way it did.

My interests sit around **AI/ML, LLMs, and agentic systems** — how models are wired into tools, how state and memory persist across steps, and what it takes to make an intelligent application reliable outside a notebook. I'm also spending time on **DevOps and cloud infrastructure**: containers, deployment, CI/CD, and the parts of the stack that decide whether software actually holds up.

I'd rather understand the tradeoffs behind a system than collect certifications, and I'm most useful when I'm building something concrete.

## 06 · Selected projects

### [TENET-AI](https://github.com/sarvajithsankar/TENET-AI) <sub>· LLM security middleware</sub>

A defensive middleware layer for LLM applications that inspects inbound prompts for injection, jailbreak, and data-extraction patterns before they reach the model. Contributed during **SSoC Season 5**; the stack uses Redis for repeat classification and an append-only PostgreSQL audit trail, deployed with Docker and Kubernetes.

<sub>`Python` `FastAPI` `Redis` `PostgreSQL` `Docker` `Kubernetes` · [live demo](https://tenet-aiorg.vercel.app)</sub>

### [Sentinel-Vault](https://github.com/sarvajithsankar/Sentinel-Vault) <sub>· SIEM prototype in C++17</sub>

A systems-level security monitor: ingests raw auth logs, rebuilds event chronology with merge sort, scores blacklisted IPs through an AVL-tree threat engine, and mirrors vault state with RAID-1-style persistence.

<sub>`C++17` `AVL trees` `merge sort` `binary I/O` `RAID-1`</sub>

### [Wafer_Anomaly_Detector](https://github.com/sarvajithsankar/Wafer_Anomaly_Detector) <sub>· auditing an ML evaluation</sub>

Reviewed a PyTorch wafer-defect notebook that reported F1 ≥ 0.90, identified the evaluation defects that invalidated the metric, repaired the pipeline, and documented honest results at the natural defect prevalence.

<sub>`Python` `PyTorch` `scikit-learn` `imbalanced-learn` `model evaluation`</sub>

### [Vit-Smart-Assistant](https://github.com/sarvajithsankar/Vit-Smart-Assistant) <sub>· campus assistant</sub>

A Gemini-powered assistant for VIT Vellore students, built with Streamlit. Answers questions about WiFi, library hours, and canteens, and keeps conversational context.

<sub>`Python` `Streamlit` `Google Gemini` · [demo](https://vit-smart-assistant-ypgxzyvtcwwronpclmgzdn.streamlit.app/)</sub>

<sub>Also: [customer_churn](https://github.com/sarvajithsankar/customer_churn) — gradient boosting on 7,000+ telecom records, tuned for recall (77%) via threshold moving.</sub>
